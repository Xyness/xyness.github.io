Minecraft plugins

Two claim plugins and a framework with its own addons, written in Java and running on real servers, some open source and some paid. The corner of programming I keep coming back to.

  • SimpleClaimSystem open source Chunk-based land protection: menus to claim, merge and sell territory, 30+ settings per claim, map integrations, an API for other plugins. 1.18+, Folia included. 100k+ downloads, about 700 servers, rated 4.9/5 on Spigot
  • SimpleClaimSystem 2 paid The rewrite, for servers that outgrew a single permission list: roles per claim, 130+ permissions, 70+ protection flags, rent, an exportable audit log.
  • XCore open source The framework the other X plugins sit on: three cache layers, cross-server sync over Redis, an addon loader, GUIs described in YAML, a multi-currency economy, a web dashboard.
  • XBans paid Bans, mutes, warns and jails, plus ban waves. A Bayesian chat classifier trained in five languages reads through obfuscation, and alt detection weighs eleven signals.
  • XAuctionHouse paid Fixed-price listings and live auctions in any currency XCore knows, with snipe protection, tiered bids, search and price history.
  • XLogin paid Online mode decided per player: premium accounts connect with their skin and no password, everyone else registers. TOTP two-factor, sessions shared across servers, one jar for Velocity, BungeeCord and XCore.
  • XAntiLag paid Prevention rather than cleanup: per-chunk caps, mob and item stackers, redstone clock detection, and a TPS monitor that steps up optimisation as the server degrades and back down as it recovers.
